      About
      
      
      Spreadsheets that aren't tables yet
      
      
      Business and government spreadsheets have a title in row 1, a header split across two merged rows, numbers written as (1,234), a subtotal under every department and a footnote at the bottom. kempt is the step before your database: it finds the table, cleans the values, and shows its work, so you can trust the result or override the parts it got wrong.
      
    
      

    
        
      
      1. 
        01
        
        Find the table
        
        
        Scores every row to pick the header, combines multi-row and merged headers, and skips titles, subtotals, grand totals and footnotes.
        
      
        2. 
      
      2. 
        02
        
        Type every column
        
        
        Reads accounting negatives, currencies, percents, units like ($000s), Excel serial dates and placeholders like N/A or —, then picks the narrowest exact SQL type.
        
      
        3. 
      
      3. 
        03
        
        Explain every decision
        
        
        Each guess is logged with the cells it touched, a reason in plain English and a confidence score. When it guesses wrong, flags like --header-rows, --date-order and --keep-totals override it.
        
      
        4. 
    
      

    
      
      
      
        
      Three commands
      
        
      # what kempt sees: tables, header, types, every decision
$ kempt inspect budget.xlsx
# CREATE TABLE with column comments
$ kempt ddl budget.xlsx --dialect postgres
# create the table and load the clean rows
$ kempt load budget.xlsx --dsn postgres://...

$ kempt inspect budget_report.xlsx
Columns (8):
  #  NAME           TYPE          UNIT
  3  fy2025_budget  int           $000s
  7  change_pct     decimal(2,1)  %
Decisions (26):
  A4:H5  header_merge    0.90
  A8:H8  drop_total_row  0.97
  C11    accounting_negative  0.95
      
      
      
      
      
        
          
        
        
      Postgres, MySQL, SQLite
      
        
      DDL for all three dialects. Postgres loads with COPY; Postgres and SQLite load in one transaction, so a failure changes nothing.
      
      
      
      
      
        
          
        
        
      Private by design
      
        
      Uploads are processed in memory and never written to disk. Demo schemas are queryable only with your token and are dropped after an hour.
      
      
      
      
      
        
          
        
        
      CLI and web, one binary
      
        
      Pure Go with no CGO. kempt serve runs this page, embedded in the same static binary, for Linux, macOS and Windows.
      
      
      
      
      
        
          
        
        
      Built for the mess
      
        
      Reads 1,500+ malformed and unusual test workbooks without a crash. Multiple tables per sheet, merged cells and mixed date formats included.
      
      
      
    
      

    
      
      
      
        
      Why not csvsql or DuckDB?
      
        
      They are excellent, and if your file is already a tidy table you should use them. csvsql, sq and DuckDB's read_xlsx load clean rectangular data quickly and well. kempt handles the sheets they would load as noise.
